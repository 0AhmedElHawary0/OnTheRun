# 🏃‍♂️ On The Run - 3D Unity Game

**On The Run** is a simple third-person 3D runner game built in Unity.  
You control a character running through a city environment with smooth animations and realistic textures.

## 🚀 How to Play

- **Movement**: The player moves forward automatically.
- **Controls**:
  - Use **WASD** or **Arrow Keys** to navigate the character.
  - Press **Space** to jump.
- **Goal**: Try to get the highest score by overcoming obstacles!

---

## 🛠️ How to Run

 Clone the repository:
 
   git clone https://github.com/your-username/OnTheRun.git

Open the project in Unity 2022.3.x or later

Open the SampleScene scene

Hit Play and enjoy!

## ✨ Features
🧍‍♂️ Third-person 3D character controller

🏙️ Low-poly modular street assets

💡 Realistic lighting and skybox

🔄 Mixamo character and animation integration

🎮 Smooth camera follow system

🎵 Background music & sound effects to enhance the gaming experience
